Suggested walkthrough

  1. Comandas → Nueva Comanda (new order): pick a customer, add products and send it.
  2. Comprobantes → Pedido (checkout): choose the sent order and save it to charge it.
  3. Vacíos y Envases → Registro de Vacíos: register returned containers for a customer.
  4. Listados (reports): open Resumen de Venta (sales summary, table) and Stock del puesto (stock, cards).
